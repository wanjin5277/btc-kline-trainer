# BTC K线盘感训练器

用真实历史K线训练合约盘感的单机网页应用，零依赖、零构建，打开 HTML 文件即玩。

## 文件说明

| 文件 | 用途 |
|---|---|
| `btc-kline-trainer.html` | 手机版（竖屏单列布局） |
| `btc-kline-trainer-desktop.html` | 电脑版（宽屏左右分栏，窗口窄于 900px 自动切回单列） |

## 玩法与规则

- 从币安（失败自动切 OKX，均无网时回退本地模拟）拉取 BTC/USDT 真实K线，按周期独立缓存 6 小时
- 每局随机抽取一段 120 根K线，开局只揭示前 40 根，其余随播放逐根揭开（未揭示区域有遮罩，结构上杜绝前视）
- 可点选已揭示的K线查看：日期、开/高/低/收、涨跌幅、成交量（主图下方有成交量副图）
- 初始资金 1000 USDT，杠杆 1–20 倍，逐仓保证金，多空可同时持仓
- 成交价 = 下一根K线开盘价；手续费双边各 0.05%；无资金费
- 盘中价格触及强平价即爆仓（按K线最高/最低价判定，跳空按开盘价结算），爆仓即终局
- 终局出复盘报告：收益率、胜率、盈亏比、最大回撤、逐笔明细，买卖点标注在K线上

## 使用方法

1. 下载对应版本的 HTML 文件到手机或电脑
2. 用浏览器打开即可（手机可"添加到主屏幕"获得全屏体验）
3. 首次打开需联网拉取K线数据，之后 6 小时内可离线训练

## 周期支持

1小时 / 4小时 / 日线，随时切换，切换即开新局。
